隱私權政策

法定傳染病病例定義小幫手（Chrome 擴充功能）｜最後更新：2026-06-02

一、我們不收集任何個人資料

本擴充功能不收集、不儲存、不傳送任何可識別個人身分的資料，也不含任何分析、追蹤或廣告程式碼。我們不會得知您查詢了哪些疾病。

二、本擴充功能會做什麼

  • 從公開的 GitHub 連結下載「法定傳染病病例定義」資料集（純資料，非程式碼），以顯示查詢結果。
  • 使用瀏覽器本機儲存空間（chrome.storage.local）僅用於快取上述資料集，以利離線使用與載入效能。此快取僅存在您的裝置上，不會上傳。
  • 提供右鍵選單，讓您把網頁上選取的文字帶入查詢；選取內容僅在您的瀏覽器中本機處理，不會外送。

三、權限用途說明

  • storage：在本機快取病例定義資料，供離線與快速載入。
  • contextMenus：新增「查詢病例定義」右鍵選單。
  • sidePanel：在側邊欄顯示查詢結果。
  • host_permission：raw.githubusercontent.com：下載最新的病例定義公開資料集。這是唯一會發出的網路連線，且只用於取得資料。

四、第三方

資料集託管於 GitHub（GitHub, Inc.）。下載資料時會依一般網路連線送出您的 IP 等技術性資訊給 GitHub，其處理依 GitHub 隱私權聲明。本擴充功能不會將任何資料提供給其他第三方。

五、免責

病例定義內容為衛生福利部疾病管制署之公開資料，僅供醫療人員查詢參考；實際通報前請以 疾管署官方公告為準。

六、聯絡方式

如有隱私相關問題，請至 GitHub Issues 反映。
